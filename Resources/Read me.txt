MouseScrollFix — natural trackpad, classic mouse scrolling
MouseScrollFix — natural для трекпада, классическая прокрутка мыши

INSTALL / УСТАНОВКА
  1. Drag MouseScrollFix into the Applications folder next to this window.
     Перетащите MouseScrollFix в папку Applications рядом с этим окном.
  2. Open it from Applications. It appears in the menu bar, not in the Dock.
     Откройте приложение из Applications. Оно появляется в строке меню, а не в Dock.
  3. A window will explain the one permission it needs. Click
     "Open System Settings" / «Открыть системные настройки».
     Появится окно с объяснением единственного нужного разрешения.
  4. Enable MouseScrollFix in Privacy & Security → Accessibility
     (on newer macOS: "Device Control and Data Access"), then click "Check again".
     Включите MouseScrollFix в «Конфиденциальность и безопасность» →
     «Универсальный доступ» (в новых macOS — «Управление устройствами и доступ к данным»),
     затем нажмите «Проверить снова».

WHY A PERMISSION / ЗАЧЕМ РАЗРЕШЕНИЕ
  The app changes scroll direction before macOS delivers events to applications, which
  is only possible with Accessibility access. It does not read text, does not watch the
  keyboard, does not capture the screen, has no network code, and never changes your
  system scroll setting.
  Приложение меняет направление прокрутки до того, как macOS отдаст события
  приложениям, — для этого нужен доступ Accessibility. Оно не читает текст, не следит
  за клавиатурой, не захватывает экран, не содержит кода для сети и никогда не меняет
  системную настройку прокрутки.

NOTE / ВАЖНО
  This build is signed ad-hoc, so macOS Gatekeeper may warn on first launch:
  right-click the app → Open. Keep it in /Applications: rebuilding changes the app's
  identity and macOS will ask for the permission again.
  Сборка подписана ad-hoc, поэтому Gatekeeper может предупредить при первом запуске:
  щёлкните по приложению правой кнопкой → «Открыть». Держите его в /Applications:
  при пересборке меняется идентичность, и macOS попросит разрешение заново.
